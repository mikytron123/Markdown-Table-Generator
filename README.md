# Markdown-Table-Generator

## Getting started

Install [Bun](https://bun.sh/), then install the project dependencies:

```sh
bun install
```

Start the development server:

```sh
bun run dev
```

Build the app for production and preview that build with:

```sh
bun run build
bun run preview
```

Check Vue and TypeScript types with:

```sh
bun run typecheck
```
